Project Overview and Features

I designed this full-stack web application to fulfill 21 distinct user stories, across functionalities like authentication, CRUD for reviews and shopping carts. t

User Authentication

Signup and login run on Django's built-in authentication, with the account app handling the forms and session. The navigation bar changes once users are signed in, and the cart, orders, and reviews pages are closed to anonymous visitors.

Browse and search the catalog

The home page lists every movie with its cover, title, and price, pulled from the Movie model. The search bar also allows users to search for movies by title.

Movie detail and reviews

Each movie has a detail page with its description, price, and every review left on it. Signed-in users can post a review, edit and delete views they wrote, and report inappropriate reviews written by others.

Cart

The cart lives in the session, keyed by movie id and quantity. The cart page renders each line item with a running total and lets you remove a single title or clear the whole thing.

Orders

Users get a record of what they bought, with related items by id. The orders page lists every order on the account with its date, order number, and total spent.

Process and Methodology

I approached this project using an iterative, agile methodology. While much of the rules were constrained by the textbook template and course instructions, it was a rather convenient process. Development was broken into function 20 to 40 minute sprints, so I could directly build, test, debug, and verify individual components like the database models and shopping cart logic before moving forward.

As required by the assignment, I documented this entire process via continuous Microsoft Teams video logs, 12 in total, covering chapters 2-13 from the textbook so from building the app to deploying, and also the custom user story. I addressed all 21 user stories clearly, and while most of them were done by simply following the textbook, I did continuously cross-check to make sure each layer (accounts, cart, etc) was done correctly.

When navigating challenges, which came up rather often in the videos, although were usually of syntactical nature such as incorrect file paths, text layouts, account access, and WSGI configurations during deployment, I relied heavily on analyzing server error logs both in the terminal and bash console to resolve the errors. This systematic debugging approach was sometimes slow as I read thoroughly, searched up details, and tried various solutions one by one, but ultimately, it created a foolproof final product that runs successfully.
